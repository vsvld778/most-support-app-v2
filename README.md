## Возможности публичной версии

| Раздел | Что можно сделать |
|---|---|
| Мой план | Собрать маршрут по своей ситуации, добавить и завершать задачи |
| Документы и сроки | Вести список сроков, выгружать напоминания в календарь |
| Обращения | Создать черновик, приложить файлы, вести историю действий, выгрузить материалы |
| Помощь рядом | Найти официальные сервисы, сохранить подготовку к визиту |
| Офлайн-помощь | Сохранить личную памятку и контакты, открыть загруженное приложение без сети |
| Голосовое обращение | Записать рассказ при поддержке браузера, приложить его к черновику |
| Работа и выплаты | Учитывать смены и выплаты, рассчитать разницу, подготовить досье |
| Перед подписью | Пройти проверку условий документа и подготовить вопросы специалисту |
| Проверка предложения | Отметить настораживающие признаки и сохранить вопросы для проверки |
| Моя семья | Вести семейные записи и личные задачи по каждому человеку |
| Жильё и залог | Зафиксировать условия, имущество и платежи, подготовить материалы |
| Русский для жизни | Учить фразы по ситуациям, отмечать прогресс, слушать озвучивание при поддержке браузера |
| Сравнение работы | Сопоставить доход и расходы по нескольким предложениям |
| Заявка на поддержку | Подготовить описание потребности и обращение |
| Навыки и опыт | Собрать портфолио навыков, подтверждения и выгрузить резюме |
| Маршрут переезда | Составить план до поездки и после приезда, подготовить передачу информации |

Записи связаны: из рабочих, жилищных и других сценариев можно создавать обращение, а из семейных дел и подготовки — задачи. Вложения хранятся локально в IndexedDB, остальные записи — в localStorage. Резервная копия JSON содержит записи, но не двоичные файлы. Хранилища V1 и V2 независимы.

## Границы пилота

GitHub Pages обслуживает статический интерфейс. Записи **не отправляются сотрудникам фонда автоматически**. Здесь нет действующего онлайн-приёма заявок, назначения кураторов, подтверждённой записи к партнёрам, совместного доступа семьи, серверной синхронизации, фоновых push или подключения государственных баз. Контрольные списки не являются автоматическим юридическим заключением или проверкой благонадёжности.

Голосовая запись требует разрешения пользователя и совместимого браузера. Приложение работает офлайн после успешной первой загрузки; внешние сайты офлайн не работают. Для напоминаний при закрытом приложении используется экспорт в календарь. Навигация и основные кнопки доступны на русском, кыргызском, узбекском и таджикском; новые подробные сценарии пока преимущественно на русском, пользовательские записи не переводятся автоматически.

Публичный пилот предназначен для знакомства со сценариями: используйте вымышленные примеры вместо паспортных, медицинских и других чувствительных сведений. Записи доступны другим пользователям того же профиля браузера. В профиле есть экспорт и удаление данных V2.

## Серверная часть

Каталог [`backend/`](backend/README.md) содержит отдельное Django-приложение: аккаунты, обращения, кабинет координатора и организации, ограничения доступа, аудит и API личного пространства. Для отдельного Ubuntu VPS подготовлен [пакет установки](DEPLOYMENT.md): Nginx, Gunicorn, PostgreSQL, HTTPS и ежедневные дампы базы.

На VPS серверный `runtime-config.js` включает синхронизацию личных записей после входа. Данные аккаунта не записываются в общую localStorage и не смешиваются с гостевыми записями. При конфликте версий можно скачать свою копию перед загрузкой актуальных данных. Вложения пока остаются на устройстве и разделяются по аккаунтам. GitHub Pages продолжает работать в гостевом режиме без запросов к API.

Установка сохраняет регистрацию закрытой и приём обращений отключённым до настройки оператора. Внешнее хранение резервных копий, загрузка файлов на сервер, почта и push требуют отдельного подключения.

## Разработка и публикация

Интерфейс — HTML, CSS и JavaScript без сборщика и внешних CDN. Для локального просмотра можно запустить `python3 -m http.server 8080` из корня. Для микрофона и service worker нужен localhost или HTTPS.

```sh
node --test tests/*.test.cjs
python3 tools/build-static.py
```

Сборщик копирует только явно перечисленные файлы интерфейса в `docs/`. GitHub Pages публикует ветку `main`, каталог `/docs`. Исходники backend, тесты и документация не входят в публикуемую веб-папку. В репозиторий не включены ключи, пользовательские базы и загруженные материалы.

GitHub Actions проверяет синтаксис JavaScript, пользовательские сценарии, соответствие `docs/` исходникам, Django-тесты и миграции на Python 3.12.
